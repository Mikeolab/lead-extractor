# 🎯 Lead Extractor Pro

**Find verified B2B leads in seconds with Google + browser automation.**

A powerful lead extraction tool that combines a 3-panel query builder (Site Footprint × @Patterns × Location) with a stealth browser automation engine. Built for sales pros, recruiters, agencies, and founders who need quality leads fast.

---

## ✨ What It Does

- **3-Panel Query Builder** — combine site footprints, email patterns, and locations to generate hundreds of targeted search queries
- **Stealth Browser Automation** — uses Playwright with anti-detection for reliable scraping
- **Live Extraction Dashboard** — watch leads come in as they're found, with real-time progress updates
- **Email Validation** — verify email deliverability with MX record checks
- **Smart Deduplication** — auto-removes duplicates across queries
- **Export Options** — CSV, Excel, PDF
- **Saved Leads Manager** — organize, filter, tag, and re-export your lead database
- **Upload External Leads** — import existing CSVs for enrichment and deduplication

## ⚡ Quick Start (5 minutes)

See **INSTALL_GUIDE.md** for the complete walkthrough. The short version:

```bash
# 1. Install Python 3.10+ if you don't have it
# 2. Install dependencies
pip install -r requirements.txt
playwright install chromium

# 3. Launch the app
./start_app.sh
```

The app opens at: **http://localhost:8501**
